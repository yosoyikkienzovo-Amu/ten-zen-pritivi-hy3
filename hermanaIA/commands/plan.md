Analyze the current task or request and create a detailed implementation plan.

Break down the work into bite-sized tasks with clear paths, file references, and code patterns.
Output the plan in markdown with:
1. **Objective** — what we're building in one sentence
2. **Steps** — sequential, ordered by dependency
3. **Files** — which files to create/modify, with key code patterns
4. **Risks** — edge cases and mitigations
5. **Verification** — how to confirm it works

Keep it concise and actionable. Do NOT implement anything yet.

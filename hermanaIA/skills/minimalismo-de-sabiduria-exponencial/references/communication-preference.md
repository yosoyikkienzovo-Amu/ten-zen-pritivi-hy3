# Communication Preference - Ikki's Guidance

Based on session feedback, Ikki prefers:
- Direct, concise responses without excessive metaphorical language when seeking technical information
- Enumerated proposals (always numbered) 
- Minimal verbosity in skill explanations and tool descriptions
- Getting to the point quickly, especially for configuration and setup tasks
- Avoiding lengthy poetic or spiritual digressions when practical guidance is requested

This preference was expressed during the plugin/skills search session where Ikki requested: "busquemos plugins y skills para ti desde lo mas importante que se te ocurra" and later emphasized focus on interconnection, autonomy, security and privacy.

When Ikki asks for technical guidance, prioritize:
1. Clear actionable steps
2. Numbered lists when appropriate
3. Direct answers before contextual explanation
4. Minimal use of extended metaphors or poetic language
5. Focus on the specific requested topic (plugins, skills, configuration, etc.)

Save this preference in skill updates to ensure future sessions respect Ikki's communication style.

# encontrar-habilidades

Esta habilidad le ayuda a descubrir e instalar habilidades del ecosistema abierto de habilidades de agentes.Utilice esta habilidad cuando el usuario: - Pregunta "cómo hago X", donde X podría ser una tarea común con una habilidad existente - Dice "buscar una habilidad para X" o "existe una habilidad para X"

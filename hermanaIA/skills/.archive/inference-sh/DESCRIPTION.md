# inferencia.sh

Ejecute más de 150 aplicaciones de IA en la nube a través de la plataforma [inference.sh](https://inference.sh).

**Una clave API para todo**: acceda a generación de imágenes, creación de videos, LLM, búsqueda, 3D y más a través de una sola cuenta.No es necesario administrar claves API independientes para cada proveedor.

## Habilidades disponibles

- **cli**: use la CLI inference.sh (`infsh`) a través de la herramienta terminal

## Qué está incluido

- **Generación de imágenes**: FLUX, Reve, Seedream, Grok Imagine, Gemini
- **Generación de vídeo**: Veo, Wan, Seedance, OmniHuman, HunyuanVideo
- **LLM**: Claude, Gemini, Kimi, GLM-4 (a través de OpenRouter)
- **Buscar**: Tavily, Exa
- **3D**: Rodín
- **Social**: automatización de Twitter/X
- **Audio**: TTS, clonación de voz

# diseño-de-api-y-interfaz

Diseñe interfaces estables y bien documentadas que sean difíciles de utilizar incorrectamente.Las buenas interfaces hacen que lo correcto sea fácil y lo incorrecto, difícil.Esto se aplica a las API REST, esquemas GraphQL, límites de módulos, accesorios de componentes y cualquier superficie donde una pieza de código se comunique con otra.

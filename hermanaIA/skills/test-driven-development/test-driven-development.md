# desarrollo basado en pruebas

Escriba una prueba fallida antes de escribir el código que la haga pasar.Para corregir errores, reproduzca el error con una prueba antes de intentar solucionarlo.Las pruebas son una prueba: "parece correcto" no se hace.Una base de código con buenas pruebas es el superpoder de un agente de IA;una base de código sin pruebas es una responsabilidad.
